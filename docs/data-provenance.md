## Leakage-Forbidden Features (NOT in dataset)

These features are deliberately **excluded** because they are only available after fulfillment:

- Return date
- Return reason
- Refund amount
- Refund status
- Delivery date
- Delivery satisfaction score
- Post-delivery complaint
- Return shipment tracking
- Warehouse inspection result

## Return Probability Model (Data Generation)

The synthetic return probability is generated using a logistic function of weighted risk factors:

1. **Customer return rate** (strong positive effect)
2. **Product return rate** (moderate positive effect)
3. **Order value deviation** (high deviation → higher risk)
4. **Payment method** (COD has higher return risk)
5. **Discount percentage** (high discounts → higher return risk)
6. **Is first order** (first orders have higher return risk)
7. **Product category** (Clothing/Footwear have higher return rates)
8. **Random noise** (ensures not perfectly predictable)

The target is then sampled from a Bernoulli distribution with the computed probability, ensuring the model cannot achieve perfect accuracy.
